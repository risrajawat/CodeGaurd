# 🛡️ CodeGuard

CodeGuard is an AI-powered VS Code extension that reviews your entire project, detects bugs, runtime errors, and common security issues, then automatically applies intelligent fixes using Google Gemini.

---

## ✨ Features

- 🤖 AI-powered project-wide code review
- 🐞 Detects bugs and runtime errors
- 🔒 Identifies common security issues
- 🛠 Automatically applies AI-generated fixes
- 📂 Reviews the entire project, not just a single file
- ⚡ Powered by Google Gemini
- 📝 Generates a review summary after completion

---

# 🚀 Quick Start

### Step 1: Get a Gemini API Key

Generate your free API key from:

https://aistudio.google.com/app/apikey

---

### Step 2: Configure CodeGuard

Open **VS Code Settings** (`Ctrl + ,`)

Search for:

```
CodeGuard
```

Enter your:

- Gemini API Key
- Gemini Model (Recommended: `gemini-2.5-flash`)

---

### Step 3: Review Your Project

1. Open your project in VS Code.
2. Press **Ctrl + Shift + P**
3. Run:

```
CodeGuard: Review Project
```

CodeGuard will automatically:

- Scan your project
- Detect issues
- Apply AI-powered fixes
- Generate a review summary
